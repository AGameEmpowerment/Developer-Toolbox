## Common project

This common project would ideally be converted and used as a NuGet package for other internal projects used within the Portfolio. It should represent base or common functionality shared between all or several projects.

NuGet package generation configuration has been added to the this csproj file. The package is generated in the `bin/[Configuration]` folder. The package is not pushed to any NuGet repository.
