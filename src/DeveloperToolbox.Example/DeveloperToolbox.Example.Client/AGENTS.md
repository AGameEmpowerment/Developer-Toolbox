# Client Guidelines

This is a Next.js App Router sample. Routes live under `src/app`, shared UI
components under `src/components`, utilities under `src/utils`, and localized
strings under `src/dictionaries`.

Use `npm run verify` before submitting changes. Keep tests colocated with the
code they exercise and preserve semantic HTML, keyboard access, visible focus,
and the skip link in the root layout. This client is a local-development
template, not production-ready configuration.
