# Source code

Application source examples live under this folder. Keep solution files at the
repository root and group related application, library, client, and test
projects beneath a shared product folder.

The included [`DeveloperToolbox.Example`](DeveloperToolbox.Example/README.md)
sample mirrors that layout:

```text
src/DeveloperToolbox.Example/
├── DeveloperToolbox.Example.App/
├── DeveloperToolbox.Example.Client/
├── DeveloperToolbox.Example.Lib/
└── DeveloperToolbox.Example.Tests/
```

The sample is for local development and reference. It uses public NuGet and npm
packages, generic local data, and no production deployment assumptions.
